# BOOSTRACK / 03

브라우저에서 바로 플레이하는 독립적인 로우폴리 타임어택 레이싱 게임입니다.
Three.js 렌더링과 Rapier 강체 물리를 사용합니다. PolyTrack의 간결한 타임어택에서 영감을 받았으며 원작의 코드, 음악, 차량 에셋을 사용하지 않습니다.

## 실행과 검증

```sh
npm ci
npm run dev
npm test
npx playwright install chromium
npm run test:browser
npm run build
```

Node.js 22.18 이상이 필요합니다. 물리 테스트는 실제 Rapier WASM을 실행합니다. 브라우저 테스트는 Chromium에서 키 입력, 다섯 코스 완주, 결과 저장, 고스트, 모바일 UI, 두 클라이언트 멀티 경기를 검사합니다. 테스트 드라이버는 가속/브레이크/조향만 입력하며 차량 위치를 수정하지 않습니다. `?qa=1` 개발용 입력 연결은 프로덕션 빌드에서 제거됩니다. 실행 중 소스를 변경하면 Vite가 경기를 새로고침하므로 테스트 중에는 소스를 편집하지 마세요.

## 조작

| 키 | 기능 |
|---|---|
| W / ↑ | 가속 |
| S / ↓ | 브레이크, 정지 후 후진 |
| A D / ← → | 조향 |
| Space | 브레이크 / 후륜 슬라이드 |
| C / 화면 카메라 버튼 | 추적 → 범퍼 1인칭 → 보닛 → 탑뷰 전환 (선택 저장) |
| R | 타이머·체크포인트·고스트를 초기화하고 재시작 |
| T | 타이머를 유지하고 최근 체크포인트로 복귀 |
| Esc | 일시 정지 / 재개 |

모바일에서는 GAS(가속), DRIFT(브레이크/드리프트), REV(주행 중 감속, 정지 후 후진), 좌우 조향 버튼을 사용합니다. 음악은 첫 사용자 클릭 이후 시작됩니다. 설정에서 음악/효과음, 그림자 품질, PB 고스트를 변경할 수 있습니다.

## 게임 구성

- APEX VALLEY: 넓은 계곡 고속 코스, 터보 패드, 완만한 경사.
- SKYLINE RUN: 뱅크 코너, 고도 변화, 실제 이륙 램프와 플랫폼 간 점프.
- NEON SECTOR: 연속 S코너, 헤어핀, 네온 터널.
- CASCADE RALLY: 두 번의 점프, 급강하, 큰 뱅크 코너.
- SWITCHBACK WORKS: 좌우 슬라롬 장애물, 높이가 분리된 고가 교차로, 연속 헤어핀.
- 한 바퀴 타임어택. 모든 체크포인트를 순서대로 통과한 뒤 출발선으로 돌아오면 완주합니다.
- 순방향 평면 통과 및 게이트 폭/높이 판정. 도로와 멀리 떨어져 통과하거나 체크포인트를 건너뛰면 인정되지 않습니다.
- 코스별 금·은·동 목표, 기록 비교, 30Hz 위치·회전 고스트와 체크포인트 구간 기록.
- 개인 기록/고스트는 `boostrack.v2.*` 키로 현재 브라우저에 저장됩니다. WORLD RANKING에서 코스별 세계 50위와 내 순위를 볼 수 있습니다. 복귀 없이 10분 이내 완주한 타임어택 기록은 결과 화면에서 닉네임을 입력해 등록합니다. 멀티 경기 결과는 별도로 방에서 공유됩니다.
- 온라인 기록은 기존 D1에 `s4:` 시즌으로 분리 저장하며, 브라우저별 최고 기록만 유지합니다. 동점은 공동 순위입니다. HttpOnly 쿠키가 브라우저 참가자를 식별하므로 쿠키 삭제/다른 기기에서는 내 기록으로 인식되지 않습니다. 로그인 계정 기능은 아닙니다.
- 서버는 주행 샘플의 시간, 이동 거리, 체크포인트 순서와 결승선 통과를 검증합니다. 클라이언트가 만든 경로이므로 완전한 부정행위 방지 시스템은 아닙니다. 기존 시즌 데이터는 보존됩니다.

로컬 랭킹: `npx wrangler d1 migrations apply boostrack-leaderboard --local` 후 `npm run build`, `npx wrangler pages dev dist --port 8788`. Vite의 `/api` 요청은 이 로컬 Pages 서버로 전달됩니다. 브라우저 랭킹 테스트에도 이 서버가 필요합니다.

## 실시간 멀티플레이

메뉴의 MULTIPLAYER → 닉네임 → 빠른 참가 또는 방 만들기. 친구에게 8자리 방 코드를 전달하세요. 2–6명이 참가하여 모두 준비하면 방장이 출발시킵니다. 빠른 참가는 선택한 코스와 관계없이 빈 공개 방에 참가하며, 없으면 선택한 코스로 새 방을 만듭니다. 방장은 대기실에서 코스를 변경할 수 있고 변경 시 전원 준비가 해제됩니다.

- Cloudflare Durable Objects 방별 WebSocket 서버, 20Hz 차량 전송 및 렌더 보간.
- 서버 시계로 동시 출발, 체크포인트 순서·게이트 통과·이동 거리 검증, 서버 수신 시각으로 완주 기록.
- 방장은 대기실의 **차량 간 충돌**에서 허용/비허용을 선택합니다. 기본값은 비허용이며 빠른 참가도 같은 방 설정을 따릅니다. 설정 변경 시 전원 준비가 해제되고 경기 중에는 변경할 수 없습니다.
- 충돌 허용 시 분리된 출발 그리드, 출발/복귀 후 2초 보호, 서버의 차량 크기 기반 연속 접촉 검사와 양쪽 반동을 사용합니다. 완주·이탈 차량 및 높이가 다른 고가도로 차량은 충돌 대상에서 제외됩니다. 서버가 접촉을 조정하는 캐주얼 방식으로 네트워크 지연에 따른 일시적인 겹침이 가능하며, 완전한 서버 권위 물리/안티치트 시스템은 아닙니다.
- T 복귀, 온라인에서는 R/일시 정지 불가. 첫 완주 후 45초 또는 출발 후 5분에 종료.
- 연결이 끊기면 안내 후 로비로 돌아갑니다. 레이스 중 재접속/늦은 참가는 불가하며 다음 경기에 참가하세요. 방장 이탈 시 남은 플레이어에게 방장을 넘깁니다.
- 결과 후 방장이 재경기를 선택하면 같은 방에서 다시 준비할 수 있습니다. 대기 방은 30분 후 만료됩니다.

로컬 서버: `npx wrangler dev --config server/wrangler.jsonc --port 8787`

서버 검증: `npx tsc -p server/tsconfig.json`, `node --experimental-strip-types tests/server-check.mjs` (로컬 서버 실행 필요). `MULTIPLAYER_ENDPOINT` 환경 변수로 배포 서버에도 같은 검사를 실행할 수 있습니다.

## 실제 주행 고스트와 메뉴

- 세계 랭킹의 1:1 대결은 새 버전에서 기록한 실제 위치·회전·조향·타임스탬프와 체크포인트 스플릿을 저장하고 보간 재생합니다. 추정 경로나 AI 주행을 생성하지 않습니다.
- 기존 기록은 보존하지만 원본 출처를 확인할 수 없는 고스트는 `원본 없음`으로 표시합니다. 새 버전에서 기존 최고 기록 이상으로 완주해 등록하면 원본 고스트가 함께 갱신됩니다. 기록과 고스트는 하나의 DB 업데이트로 저장됩니다.
- GARAGE에서 차체·포인트 색과 스포일러를 변경합니다. 브라우저에 저장되며 멀티 참가 시 공유됩니다. 성능은 바뀌지 않습니다.
- 메뉴는 이중 스크롤과 스크롤바를 제거하되 작은 화면에서 휠·터치로 모든 항목에 접근할 수 있습니다. 상대 닉네임은 반투명하게 표시합니다.
- 제공된 광고는 메뉴에만 화면 크기에 맞춰 최대 두 개를 배치합니다. 주행 시 제거하고 별도 sandbox 프레임으로 격리합니다. 개발 모드에서는 실제 광고 요청을 보내지 않습니다. 광고 차단기·제공사 응답에 따라 광고가 비어 있을 수 있습니다.
- Google 확인 파일은 `/google95f51eb39f52d48a.html`에서 제공합니다.

## 물리

120Hz 고정 시뮬레이션, 렌더 보간, 4륜 레이캐스트 서스펜션, 속도 비례 조향, 타이어 마찰, 공기 저항, 접지 중 다운포스, CCD 차체 충돌을 사용합니다. 일반 조향은 완만하게 진입하고 해제 시 빠르게 복원하며 SPACE 슬라이드 반응은 유지합니다. 접지/점프/착지는 Rapier가 처리하며 차량 높이를 도로 높이로 맞추지 않습니다. 노랑/검정 교차 펜스는 실제 충돌 프리즘과 같은 꼭짓점을 사용합니다. 바퀴의 지면 탐색만 펜스를 제외하고 차체는 계속 충돌하므로 펜스를 도로로 인식해 타고 오르는 문제를 방지합니다. 주변 지형은 도로 폭과 여유 거리를 확보해 배치됩니다.

## 배포

```sh
npx wrangler d1 migrations apply boostrack-leaderboard --remote
npx wrangler deploy --config server/wrangler.jsonc
npm run deploy -- --branch main
```

기존 Cloudflare Pages 프로젝트 `boostrack`과 Worker `boostrack-multiplayer`를 사용합니다. 기본 운영 서버는 `https://boostrack-multiplayer.valorant.workers.dev`이며 `VITE_MULTIPLAYER_URL`로 빌드 시 변경할 수 있습니다. 다른 Pages 도메인으로 옮기면 서버의 Origin 허용 목록도 바꿔야 합니다. Pages 배포에는 `/api/leaderboard` 함수와 기존 D1 바인딩이 포함됩니다. `npx tsc -p functions/tsconfig.json`으로 API 타입을 검증합니다. 서버는 생성 빈도/메시지 크기/전송 빈도/방 정원을 제한하지만 공개 서비스의 과금·악용 모니터링은 Cloudflare 대시보드에서 지속적으로 관리해야 합니다.
